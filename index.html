Boredom Bot — Install

Install the Boredom Bot widget on any page. Host widget.js in this repo (or elsewhere) and the buttons below will inject it into the current page.

Copy bookmarklet Download userscript
After you enable Pages the bookmarklet and userscript will work.
Click "Copy bookmarklet" to copy it to clipboard.
Quick instructions:
  1. Create the file widget.js in this repo with your widget code.
  2. Enable Pages (branch: main / folder: root).
  3. Visit the published site and use the buttons to run or install the widget.
